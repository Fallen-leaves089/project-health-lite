# 结构经验（轻量版）

这是一本空白起步的结构经验提示册。它用于帮助第一次体检发现问题，不替代专业版 `project-health` 的结构经验受控写入器。

## 使用原则

- 只在完成项目证据检查后翻阅；不先翻手册再反推项目问题。
- 一次最多看 1-2 章，只把条目当“可能需要复核”的提示。
- 区域为空就继续检查，不写占位条目；没有经验不写占位条目。
- 只有已核实、可复用、边界清楚且不与 `PITFALLS.md` 重复的经验才写入用户本地的 `STRUCTURE.local.md`；没有合格经验就保持空白。
- **自动回收**：每次任务结束、写最终报告前执行；合格经验由 Agent 直接写入 `STRUCTURE.local.md`，不等用户提醒。没有合格经验写“无新增”，首次创建本地手册前说明路径，写入失败则保留待记录内容并报告。
- 轻量版只使用软提示，不把结构经验变成详细规则或检查清单。

## 索引

| 章 | 何时可能命中 | 关联避坑 |
|---|---|---|
| A 边界与所有权 | 数据、账号、接口或权限归属不清 | U-04、U-08、U-44 |
| B 依赖与故障传播 | 外部服务、同步链路、端口或启动依赖不清 | U-15、U-18、U-19 |
| C 状态与一致性 | 数据库、迁移、备份、缓存或重复操作 | U-24-U-28、U-42 |
| D 环境与启动 | 本机、生产、系统、路径或配置差异 | U-17、U-20-U-23 |
| E 证据与假绿 | 测试通过但没验证行为，或只看 AI 自述 | U-08、U-39、U-44 |
| F 演化与交付 | 部署包、回滚、交接和版本不一致 | U-34、U-42、U-43 |

## 条目格式

`S-<A-F>-<三位编号> | 已验证/待验证/已过时 | 触发信号 | 结构机制 | 边界/反例 | 验证抓手`

- 新条目默认从 `待验证` 开始，并从已有同类 ID 的下一个编号继续；不得为了占位而创建条目。
- 每条只写已核实的机制，不写目标项目原文、客户信息、绝对路径、密钥或猜测。
